Cinema Room Manager 🎟️
A console-based cinema booking system built with Kotlin.
This project allows users to view available seats, purchase tickets, and check booking statistics through an interactive menu-driven interface.
Features


View cinema seating arrangement


Buy tickets with seat selection


Prevent double booking


Dynamic ticket pricing system


Booking statistics:


Purchased tickets


Percentage of occupied seats


Current income


Total possible income




Input validation and error handling


Tech Stack


Kotlin


Console Application


Concepts Used


Functions


Arrays (2D Array)


Loops & Conditions


Exception Handling


Variables & State Management


Menu-driven programming
